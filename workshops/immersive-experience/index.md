# GitHub Copilot Immersive Experience

Welcome to the **GitHub Copilot Immersive Experience** — a scenario-based workshop where you'll tackle real development problems that mirror your daily work. The GitHub Copilot app is the recommended orchestration surface, with the IDE, CLI, and GitHub.com used where each is strongest.

This workshop uses the [Octocat Supply](https://github.com/copilot-academy/octocat_supply) demo application as a foundation. Make a copy of this repository to follow along with the exercises, or adapt the scenarios to your own codebase.

## What You'll Accomplish

By the end of this workshop, you'll have hands-on experience with:

1. **Agent-Driven Development** — Plan, build, verify, and review changes in isolated sessions
2. **Parallel Work** — Direct multiple workstreams without sharing uncommitted changes
3. **Code Quality & Testing** — Improve test coverage and code maintainability
4. **Security** — Catch issues before a pull request and remediate repository alerts
5. **Code Review** — Investigate pull requests, resolve feedback, and keep humans accountable
6. **Customization** — Use instructions, custom agents, skills, plugins, MCP servers, and canvases
7. **Automation** — Choose between recurring app automations and shared repository workflows

## Getting Started

Start with [Setup](/workshops/immersive-experience/setup), take the [GitHub Copilot App Tour](/workshops/immersive-experience/copilot_app), then work through the use cases in order. Each module is self-contained but builds on skills from earlier exercises.

## Prerequisites

- GitHub account with appropriate permissions
- [GitHub Copilot app](https://docs.github.com/en/copilot/get-started/quickstart-copilot-app) installed and enabled by your organization
- Git installed locally
- Basic command line knowledge
- Optional: [Visual Studio Code](https://code.visualstudio.com/) with the [GitHub Copilot extension](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot), or a GitHub Codespace
